Design Methodology

How I approach analog circuit development.

1. Architecture Selection

Topology tradeoffs, gain-bandwidth targets, noise constraints, headroom planning.

2. Device-Level Design

Biasing + sizing, operating region checks, common-mode control, stability strategy.

3. Verification

AC, transient, noise, CMRR/PSRR, loop stability, corners/PVT sweeps.

4. Documentation

Annotated schematics, clear testbenches, readable plots, reviewer-friendly summaries.

About

Quick context.

I design and verify transistor-level CMOS analog and mixed-signal building blocks with emphasis on stability, robustness, and clean verification methodology. My work includes OTAs, Gm-C filters, switched-capacitor systems, and biasing networks validated using structured AC/transient/noise analysis.

Note: Source schematics/layout files are often course/IP-restricted, so this site focuses on architecture, testbenches, and simulation results.
